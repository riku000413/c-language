「c言語ミスメモ」

入出力(printf scanf)
* `scanf` で変数の前に `&` が必要
* `scanf` の引数の間にはカンマ `,` が必要！
* `printf` で変数の中身をだすときは `%d` を使う（`printf("h:m:s")` だと文字がそのまま出る）

if文
* C言語では `a < b < c` みたいな3つつなげる書き方は不可！
  `a < b && b < c` のように `&&` (AND) で分ける。
* `if` の条件は丸かっこ `( )`、実行処理は波かっこ `{ }` で囲む。
* `if` や `for` の直後（かっこ文末）に `;` はつけない！

AND / OR の使い分け
* AND（かつ）：`&&` ➔ すべての条件を満たす（3つ以上繋げてもOK）
* OR（または）：`||` ➔ どれか1つでも条件を満たす

図形・範囲の条件判定（境界線）
* 境界ぴったりも含めるなら `<` ではなく `<=`（以下）を使う
* 図形（円など）が枠内に収まる判定は、上下左右すべての境界を `&&` で繋ぐ

トラブルシューティング
* GitHubと手元の履歴がズレたら `git pull --rebase origin main` で解決。

for文の書き方と変数i
* 基本構文：`for (①初期化; ②継続条件; ③毎回の処理)`
  * ①初期化（`i = 1`）：ループ開始時に1回だけ実行される（forのカッコ内に書くのが基本！）
  * ②条件（`i <= 1000`）：この条件を満たす間ループする
  * ③変化（`i++`）：1回処理が終わるごとに実行される
* `i` の宣言場所：
  * 現代的：`for (int i = 0; ...)` （ループ内限定で使えて安全）
  * 伝統的：関数の先頭で `int i;` と宣言してから `for (i = 0; ...)` と書くのもOK！
  for文のセミコロン区切りルール
* for文のカッコ内は、どんな時も **セミコロン `;` が必ず2つ** 必要！
  * 基本形: `for (①初期化; ②条件; ③更新)`
* **初期化を省略する場合（ループの前で変数を用意した時など）：**
  * ❌ `for(a <= b; a++)` ➔ セミコロンが1つしかないのでエラー！
  * ⭕ `for(; a <= b; a++)` ➔ 先頭に `;` を置いて「初期化はスキップ」と伝える！
* `a++`（一番右）の直後に `;` は不要（カッコ `)` で閉じるだけ）。

break文（ループの中断）
* `break;` は「自分が直接入っている一番近いループ（カッコ `{ }`）」を1つ破って脱出する！
* 二重ループの中で `break` しても、破れるのは内側のループだけ（外側はそのまま継続する）。
* 特定の入力（例：`0` が来たら終了）でループを止めたい時は `if (x == 0) break;` と書くのが定番。

return（関数の終了と結果の返却）
* `return 0;` ➔ プログラムが「正常終了」したことをOSに報告する。
* `return 1;` などの0以外の値 ➔ エラーが発生して「異常終了」したことを報告する。
* ループだけ抜けるなら `break`、プログラム自体を即終了するなら `return` を使う！

main関数の return 0; 省略
* C99規格以降、`main` 関数の最後の `return 0;` は省略しても自動補完される。
* ただし、途中で処理を打ち切りたいときの `return 1;`（異常終了）などは明記が必要！

## 型の使い分けと変換指定子（完全版）

 型名 | 使い分け（どんな時使う？） | scanf | printf |
|:--- | :--- | :--- | :--- |
| **`int`** | **整数**（小数がつかない数） | `%d` | `%d` |
| **`float`** | **単精度小数**（精度が少し低い小数・有効数字約6桁） | `%f` | `%f` |
| **`double`** | **倍精度小数**（精度の高い小数・有効数字約15桁 / **小数は基本これ！**） | `%lf` | `%lf` |
| **`char`** | **半角1文字**（`'a'`, `'1'` など） | `%c` | `%c` |

printfの桁数指定まとめ
* 小数点以下のみ固定: `%.5lf` （小数第5位まで）
* 全体の表示幅（右揃え）: `%5d` （5文字分の幅を確保）
* ゼロ埋め: `%05d` （空きを 0 で埋めて5桁にする）

整数どうしの割り算の仕組み
* `int / int` ➔ **端数切り捨ての整数**（四捨五入ではなく切り捨て！例: 9 / 10 ➔ 0）
* **理由:** C言語は型を自動変換せず、整数どうしの計算は整数用回路で処理するため。
* **解決法:** `(double)a / b` のように片方をキャスト（型変換）すると小数計算になる。

型変換（キャスト）
* 書き方: `(変換したい型名)変数`
* 意味: 一時的にその型として計算させるテクニック。
* 例: `(double)a / b` ➔ `int` の `a` を一時的に `double` にして割り算することで、小数点以下まで正確に計算できる。

## 文字（char）のルール
* **シングルクォーテーション `' '` で囲む:**
  * 文字（`'?'`, `'+'`, `'A'` など）は必ず `' '` で囲む[cite: 4]。
  * 囲まないと「変数名」として認識され、コンパイルエラーになる[cite: 4]。
* **数値との違い:**
  * 数値（`0`, `100`）：囲まない（例: `if (a == 0)`)
  * 文字（`'0'`, `'?'`）：囲む（例: `if (op == '?')`)

## 配列（Array）の基本ルールと使い方
* **宣言**: `int a[100];` （整数が100個入る棚を作成）
* **部屋番号（インデックス）**: **`0` から始まる**（例：`a[0]` 〜 `a[99]`）
* **注意**: `a[100]` は存在しない（範囲外アクセスでバグの原因になる）
## 2次元配列（Array）の基本ルールと使い方
* **宣言:** `int cards[4][14] = {0};`（全マスを `0` で初期化）
* **イメージ:** **「たて × よこ」の下駄箱**
  * 1次元配列: `a[10]` ➔ **1列のロッカー**
  * 2次元配列: `a[4][14]` ➔ **4行14列の下駄箱**
* **部屋番号:** `cards[行][列]`（例: `cards[0][1]` は0行目1列目）
* **フラグ管理:**
  * 配列の中に文字（`"S 1"` など）は入れない。
  * **専用の部屋**を用意し、中身は **`1`（ある）** か **`0`（ない）** だけを入れる。

## `scanf` と入力バッファ（改行 `\n`）のルール
* **`%d`（数値）:** 前の改行（Enter）やスペースを **自動で無視** してくれる。
* **`%c`（文字）:** 前の改行（Enter）を **`\n` という文字** として拾ってしまう[cite: 5]。
* **事故の原因:**
  * `scanf("%d", &n);` の Enter（`\n`）が残る。
  * 次の `scanf("%c", &skin);` が **`\n`** を読み込んでバグる[cite: 5]。
* **解決策（スペースのおまじない）:**
  * **書き方:** `scanf(" %c %d", &skin, &number);`[cite: 5]
  * **意味:** `%c` の前に **半角スペース** を置くと、残った改行を無視して文字を拾う[cite: 5]。
